TradeRoute Help Page

Symbol Map:
Optional

Elements with this symbol are optional and do not require a value.
Unresolved
 Elements with this symbol need to be resolved. Enter the correct value and click the orange tick to resolve the value.
Resolved
 Elements with this symbol have been automatically resolved. Their values can be changed.
Invalid
 The value you entered in the current field is not a valid value. Click on the cross to bring up a list of valid values.
Locked
Elements with this symbol are locked and their values cannot be changed.
Copy Value
 Copy your partner's value into the current field, you can modify this once it has been copied.
Field Zoom
Opens the contents of the current field in a seperate window so you can view/modify the contents of the field.
Field Help
 Opens a pop up window which contains relevant help information about this field.

 

Transaction Options:

Help
 Displays this page.
Cancel
 Cancels the current transaction, no changes are saved.
Save
 Saves all changes to the current transaction.
Reject
 Reject the current transaction, an acknowledgement is generated, and sent to your trading partner.
Accept
 Accept the current transaction for entry into the host system. An acknowledgement is genereated and is sent to your trading partner.
Print
 Print a copy of the current transaction to your default printer.
CheckValues
 Validate the current values on the screen.
